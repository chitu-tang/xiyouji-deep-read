# 原文素材库：历史定位材料

本目录保留仓库既有的百回文本定位材料，供研究导航、情节定位和候选问题发现使用。它不是人民文学出版社 2020 年版三卷正式底本，也不能替代运行方对正式 PDF 首末页和逐实例引文的视觉核验。

## 文件命名规则

```text
chapter-001.md  →  第一回
chapter-002.md  →  第二回
...
chapter-100.md  →  第一百回
```

## 使用边界

- 可用于回目定位、情节检索、研究线索和候选角度发现。
- 不得作为正式文章直接引文的唯一来源。
- 正式引文必须回到运行方注册的人民文学出版社 2020 年版上、中、下三册 PDF，并由 0B/0C 台账核验。
- 在线文本、OCR、搜索结果和本目录材料只能作定位或线索，不能绕过正式底本门禁。

## 当前状态

本目录中的文本不承担正式底本身份。使用 RC.2.4 管线时，先运行 `scripts/preflight-0a.sh`，再按单回目完成 0B 范围核验。
