## 文件组织

```
scholarship/
├── by-scholar/          ← 按学者索引
│   ├── liubo.md
│   ├── liuyongqiang.md
│   └── ...
└── by-theme/            ← 按主题索引
    ├── sun-wukong-origin.md    ← 孙悟空形象来源
    ├── xuanzang-history.md     ← 玄奘历史原型
    ├── version-studies.md      ← 版本学
    ├── religious-reading.md    ← 宗教解读
    └── folk-literature.md      ← 民间文学规律
```

## 单条格式

```markdown
### [学者名]：[论点标题]

**来源**：《著作/论文名》，出版社/期刊，年份，页码（如有）
**核心论点**：[1-3句话概括]
**关键引文**：
> [原文摘录]
**适用回目**：第X回、第Y回
**解读角度**：[该论点可支撑的解读方向]
```
