# 故事蓝本素材库

本目录存放《西游记》情节的故事原型/蓝本材料，按情节单元索引。

## 收录来源

| 来源 | 类型 | 与西游的关系 |
|------|------|-------------|
| 《大唐西域记》 | 玄奘口述、弟子辑录 | 取经故事地理/传说原型 |
| 《大慈恩寺三藏法师传》 | 弟子撰传记 | 玄奘生平一手材料 |
| 《罗摩衍那》 | 印度史诗 | 孙悟空/哈奴曼形象源流 |
| 元杂剧西游戏 | 戏曲 | 西游故事演变中间态 |
| 宋元话本 | 说书底本 | 世代累积的叙事层 |
| 唐传奇（《白猿传》《杜子春》等） | 文言小说 | 本土猿猴文化/故事原型 |
| 《大唐三藏取经诗话》 | 宋代话本 | 西游故事最早完整形态 |

## 文件组织

```
story-sources/
├── by-episode/          ← 按西游情节单元索引
│   ├── monkey-origin.md       ← 孙悟空形象源流
│   ├── xuanzang-journey.md    ← 玄奘西行史实
│   ├── havoc-in-heaven.md     ← 大闹天宫原型
│   └── ...
└── by-source/           ← 按来源文献索引
    ├── datang-xiyu-ji.md      ← 《大唐西域记》相关故事
    ├── ramayana.md            ← 《罗摩衍那》相关故事
    ├── yuan-zaju.md           ← 元杂剧相关
    └── tang-chuanqi.md        ← 唐传奇相关
```
