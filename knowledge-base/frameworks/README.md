# 思想框架工具箱

本目录存放解读《西游记》时可用的思想框架，作为"解读工具箱"使用。
每个框架是一个独立的分析透镜，适用于不同回目。

## 收录框架

### 1. 心学框架（xinxue.md）
- 孟子"四端""放心""求放心"
- 王阳明"心外无物""致良知""知行合一"
- 明代心学思潮对通俗文学的渗透
- 西游记中"心猿""意马"的心学隐喻
- 适用：孙悟空形象、紧箍咒、取经动机、回目中含"心"字的回目

### 2. 内丹学框架（neidan.md）
- 全真教内丹术语：金公、木母、黄婆、婴儿、姹女
- 龙虎交媾、坎离既济
- 西游记回目中的内丹密码
- 清代评点本（汪憺漪、刘一明）的内丹解读路径
- 适用：含内丹术语的回目、修炼/炼丹情节

### 3. 佛教世界观框架（buddhism.md）
- 四大部洲、须弥山、三千大千世界
- 轮回、因果、业报
- 禅宗 vs 净土宗 vs 法相宗（唯识宗）
- 民间佛教 vs 精英佛教
- 适用：世界观设定、宗教情节、佛祖/菩萨出场回目

### 4. 民间文学规律框架（folk-literature.md）
- 世代累积型作品的创作规律
- "好君主无能化"套路
- 冒险故事 vs "人折腾人"故事
- 口头文学传统（韵语为口说而设）
- 听众/读者期待对故事走向的塑造
- 适用：唐僧形象、情节模式化回目、韵文分析

### 5. 比较文学框架（comparative.md）
- 中印文学交流（丝绸之路、海上丝绸之路）
- 故事传播与本土化改造
- 跨文化形象比较（哈奴曼 vs 孙悟空）
- 适用：孙悟空形象源流、异域情节

## 文件格式

每个框架一个 .md 文件，包含：
```markdown
# [框架名称]

## 核心概念
[该框架的关键术语和概念，用口语解释]

## 在西游记中的体现
[具体回目、情节、人物如何体现该框架]

## 使用指南
[解读时如何运用该框架：从哪个角度切入、注意什么、避免什么]

## 关键引文
[支撑该框架的原文/学者论述]

## 适用回目索引
[哪些回目最适合用该框架解读]
```
