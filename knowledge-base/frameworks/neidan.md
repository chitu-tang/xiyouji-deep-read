# 内丹学框架

## 核心概念

### 全真教内丹术语
- **金公**：孙悟空（"金"字旁加"公"= 铅，内丹术中铅代表阳/心）
- **木母**：猪八戒（"木"字旁加"母"= 汞，内丹术中汞代表阴/肾）
- **黄婆**：沙僧（调和金木的中介）
- **婴儿**：内丹修炼中的阳神
- **姹女**：内丹修炼中的阴神
- **心猿**：孙悟空（心像猴子一样躁动）
- **意马**：小白龙（意念像马一样奔跑）

### 内丹修炼基本逻辑
- 人体即炉鼎
- 精气神为药物
- 修炼 = 在体内"炼丹"
- 坎离既济：水火交融，阴阳调和
- 龙虎交媾：心火（龙）与肾水（虎）相交

### 西游记回目中的内丹密码
- 第十九回：云栈洞悟空收八戒 **浮屠山**玄奘受心经
- 第三十二回：平顶山**功曹**传信 莲花洞**木母**逢灾
- 第三十八回：婴儿问母知邪正 **金木**参玄见假真
- 第四十回：婴儿戏化禅心乱 **猿马**刀归木母空
- 第四十一回：**心猿**遭火败 **木母**被魔擒
- 第七十六回：**心神**居舍木归土 **性**主含光**情**顺金
- 第八十六回：木母助威征怪物 **金公**施法灭妖邪

## 在西游记中的具体体现

### 清代评点本的内丹解读路径
- **汪憺漪《西游证道书》**（康熙年间）：最早系统用道教内丹解读《西游记》
- **刘一明《西游原旨》**（嘉庆十五年）：全真教道士，最彻底的内丹解读
  - 认为《西游记》全书就是一部内丹修炼手册
  - 每个妖怪 = 修炼中的一个障碍/偏差
  - 取经过程 = 炼丹过程
- **陈士斌《西游真诠》**（康熙丙子）：也走内丹路径

### 鲁迅对内丹解读的态度
> 然作者虽儒生，此书则实出于游戏，亦非语道，故全书仅偶见五行生克之常谈。

> 道士说，这部书是一部金丹妙诀……这些解说都是《西游记》的大仇敌。（胡适）

### 但内丹元素确实存在
- 回目中的术语（金公、木母、心猿、意马）不是偶然的
- 全真教道士确实参与了《西游记》的创作/传播过程
- 有些内丹内容确实做到了和情节融为一体，不是那么容易剔除
- 刘勃的态度：全真教的内容"有的还真是做到了和情节融为一体"

### 具体例子
- 孙悟空被压在五行山下 = 心猿被制（内丹术中"降心"）
- 紧箍咒 = 约束心猿的手段
- 火焰山 = 心火过旺（需要芭蕉扇=阴水来调）
- 通天河 = 坎水（内丹术中的关键关卡）
- 灵山 = 丹田（修炼的终点）

## 使用指南

### 切入角度
- 问"为什么回目里有'金公''木母'？" → 内丹术语，全真教参与创作
- 问"为什么孙悟空属金、猪八戒属木？" → 内丹五行配属
- 问"为什么火焰山需要芭蕉扇？" → 心火过旺需阴水调
- 问"为什么清代道士认为这是'证道书'？" → 内丹解读路径的历史

### 注意事项
- 内丹解读是清代评点本的重要路径，但不是唯一正确路径
- 鲁迅、胡适明确反对过度内丹解读
- 现代学术的态度：承认内丹元素存在，但不认为全书就是一部内丹手册
- 使用时必须标注为"古人观点"（清代评点本路径）
- 可以介绍这个解读路径本身（作为接受史），但不必全盘接受

### 避免
- 不要把每个情节都硬套内丹解释
- 不要说"作者一定是在写内丹修炼"
- 不要忽略鲁迅/胡适的批评（"这些解说都是《西游记》的大仇敌"）
- 不要把内丹解读和心学解读混为一谈（虽有重叠，但逻辑不同）
