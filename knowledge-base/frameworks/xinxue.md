# 心学框架

## 核心概念

### 孟子"放心"与"求放心"
- **四端**：恻隐之心、羞恶之心、辞让之心、是非之心 → 仁义礼智的源头
- **放心**：把善良的本心弄丢了（"放"是放逐、放弃，不是今天的"安心"）
- **求放心**：把丢掉的善良本心找回来
- 原文："学问之道无他，求其放心而已矣。"（《孟子·告子上》）

### 王阳明心学
- 心外无物、心即理
- 致良知
- 知行合一
- 明代中后期天下读书人或多或少都会谈两句"阳明心学"

### 在西游记中的体现
- "心猿"：孙悟空 = 一颗不安分的心
- "意马"：小白龙 = 意念
- "心猿意马"：合起来就是人心的躁动
- 全书一百回，"心"字在回目中出现了31次

## 在西游记中的具体体现

### 回目中的"心"字
- 第一回：灵根育孕源流出 **心性**修持大道生
- 第七回：八卦炉中逃大圣 五行山下定**心**猿
- 第十四回：**心**猿归正 六贼无踪
- 第三十回：邪魔侵正法 **意**马忆**心**猿
- 第四十一回：**心**猿遭火败 木母被魔擒
- 第四十六回：外道弄强欺正法 **心**猿显圣灭诸邪
- 第五十六回：神狂诛草寇 道昧放**心**猿
- 第五十七回：真行者落伽山诉苦 假行者水帘洞誊文（二心之争）
- 第五十八回：二**心**搅乱大乾坤 一体难修真寂灭
- ……（共31次）

### 第一回的"求放心"寓言（刘勃解读）
- 石猴 = 天地之心（石头迸裂产一石卵，圆球即心）
- 花果山水帘洞 = 心有了安放的地方（洞天福地）
- 石猴想到死亡 → 离开洞天福地 → 到尘世间（南赡部洲）
- 樵夫指路 → 灵台方寸山斜月三星洞
  - "灵台""方寸"都是古人对"心"的称呼
  - "斜月三星"= 心字的象形（卧钩=斜月，三点=三星）
- 整个第一回 = 天地之心离开本位，经过尘世，重新找回自己的心的寓言

### 谢肇淛的总结（《五杂组》卷十五）
> 《西游记》曼衍虚诞，而其纵横变化，以猿为心之神，以猪为意之驰，其始之放纵，上天下地，莫能禁制，而归于紧箍一咒，能使心猿驯伏，至死靡他，盖亦求放心之喻，非浪作也。

### 紧箍咒 = 驯服心猿的手段
- 心猿开始是放纵的（大闹天宫）
- 紧箍咒来了 → 心猿被驯服
- "至死靡他" → 再也没有别的想法
- 这就是"求放心"：把放纵的心收回来

### 六贼（第十四回）
- 眼看喜、耳听怒、鼻嗅爱、舌尝思、意见欲、身本忧
- 佛教"六根"（眼耳鼻舌身意）的拟人化
- 孙悟空打死六贼 = 心猿归正，斩断六根

### 二心之争（第五十七至五十八回）
- 真假美猴王 = 一个人的两颗心
- 六耳猕猴 = 孙悟空的"二心"
- 如来识破 → 孙悟空打死六耳猕猴 = 消灭二心，一心向佛
- 此后孙悟空再未离开唐僧

## 使用指南

### 切入角度
- 问"为什么孙悟空是猴子？" → 心猿，心像猴子一样躁动不安
- 问"为什么有紧箍咒？" → 驯服心猿的手段，"求放心"
- 问"为什么灵台方寸山、斜月三星洞？" → 都是"心"的隐喻
- 问"为什么真假美猴王？" → 二心之争，消灭杂念
- 问"为什么回目里这么多'心'字？" → 全书是"求放心"的寓言

### 注意事项
- 心学解读是清代评点本的主流路径之一，但不是唯一路径
- 鲁迅、胡适反对过度往这个方向解读（"这些解说都是《西游记》的大仇敌"）
- 但刘勃等现代学者认为：作者确实受时代氛围影响，读者也确实往这个方向解释，两者都是事实
- 使用时应标注：这是"古人观点"（评点本路径）还是"现代学术共识"

### 避免
- 不要把每个情节都硬套心学解释
- 不要忽略其他解读路径（民间文学、滑稽/玩世、故事演化）
- 不要说"作者一定是在写心学"，而说"可以从这个角度读"
