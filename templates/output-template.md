# 交付格式模板（Step 7）

> 本文件定义最终交付物的格式。Step 7 按此模板输出。

---

## 单篇交付格式

```
═══════════════════════════════════════
第X回 · 第Y篇（共Z篇）
═══════════════════════════════════════

[网感标题]


[正文，含段落小标题]

[段落小标题1]

……

[段落小标题2]

……

[收束]


───────────────────────────────────────
参考文献
───────────────────────────────────────

[1] [明] 百回本《西游记》（世德堂本），第X回
[2] [清] 刘一明，《西游原旨》，第X回批语
[3] 刘勃，《……》，……
[4] ……

═══════════════════════════════════════
```

---

## 多篇交付格式

若本回解读为多篇（2-5篇），在所有文章之前附一个**回目总纲**：

```
═══════════════════════════════════════
第X回 解读总纲
回目：[回目全称]
篇数：X 篇
═══════════════════════════════════════

[200字以内的总纲，概括本回解读的整体脉络：
本回讲了什么 → 我们从哪几个角度切入 → 每篇分别解决什么问题]

各篇目录：
1. [第1篇标题]
2. [第2篇标题]
3. ……

═══════════════════════════════════════

[第1篇完整内容]

═══════════════════════════════════════

[第2篇完整内容]

═══════════════════════════════════════
```

---

## 格式说明

- 正文为纯文本，可直接用于口播朗读
- 段落小标题保留（线下分享时可作为提示词，公众号排版时作为小标题）
- 参考文献列表附在每篇文末
- 不使用 Markdown 格式标记（无 #、无 **、无 - 列表符号）
- 段落之间空一行
- 引文段落前后可空一行，视觉上区分

---

## 附加信息（交付时一并告知用户）

```
【交付说明】
- 本回解读共 X 篇，总计约 XXXXX 字
- 审核状态：三重审核全部通过 / 有 X 处残留问题（见下）
- 素材缺口：[若有]
- 建议：[若有后续可追加的角度]
```

若存在残留问题（3轮修改后仍未解决）：

```
【残留问题】（需人工处理）
1. 第X篇第X段：……（原因：……）
2. ……
```

---

## 公众号转化备注

若用户需要将口播稿转化为公众号文章，注意：
- 口播稿的段落小标题 → 公众号的小标题/加粗
- 口播稿中的引文 → 公众号中可用引用格式或单独成段
- 口播稿中的"喘气"短句 → 公众号中可保留，增加阅读节奏
- 参考文献 → 公众号中可放文末"延伸阅读"或脚注
- 口播稿中"我给你念一下"这类口语 → 公众号中改为"原文是这么写的"

（此转化由用户另行指示，不在本 skill 管线内自动执行）
