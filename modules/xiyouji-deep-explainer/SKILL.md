# 《西游记》研究性初稿器（第 6 步）

## 必读输入

- 单篇状态卡；
- 第 5 步完整文章设计包；
- 第 2 步研究交付包；
- 0B 定位与 0C 引文台账；
- 正式底本注册表；
- `references/研究性长文-活人感规范.md`。

## 执行流程

1. 6A 交接预检：锁定文章设计、策略、主轴、范围、上游版本和待核项。
2. 6B 全篇论证骨架：为每个章节任务指定原文锚点、材料角色、理解变化和断言上限。
3. 6C 关键主张展开：按“原文 → 校注/评点 → 现代研究 → 本文判断”建立证据链，标出最弱环节。
4. 6D 逐节研究性写作：每个核心段落先写可见现象，再写解释和边界；保留断言层级、引文 ID 和待核标记在映射层。
5. 6E 异说与风险复核：列出代表性替代解释、来源范围和不可裁决项。
6. 6F 全篇整合：检查章节依赖、理解变化、主轴继承、引文状态和研究/读者双轨质量门。

不逐节等待用户。核心证据、中心论题、解释边界或主导策略变化时，提交回退请求；不能把研究缺口留给第 7 步用语言填充。

## 输出

`research/第X回-篇号-主题-研究性初稿.md` 固定包含：论题与暂定结论、关键原文细读、分论点证据链、主张—证据映射、异说与待核、章节研究性草稿、研究责任线/读者表达线检查和 `HANDOFF_READY`。

研究性初稿完成后状态为“研究性初稿完成，待正式写作”，不要求用户逐节确认。
