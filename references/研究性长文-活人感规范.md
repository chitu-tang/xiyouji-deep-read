# 《西游记》研究性长文的活人感规范

> 适用范围：回目深度长文的研究性初稿、正式写作与终审。
> 目标：让读者感觉有一个正在阅读、取舍和判断原文的人，而不是让文章伪装成非 AI 文本或套用聊天口吻。
> 前提：活人感建立在可核验的原文、材料与作者判断之上；它不能取代版本、引文、归因和论证责任。

## 一、三层来源

一段有分量的解读通常同时有三层，顺序不能倒置：

1. **文本可见**：一个字、一个动作、一次叙事顺序或人物反应，能回到原文定位。
2. **材料支撑**：校注、评点或研究说明此处可怎样理解，或为何有争议。
3. **本文判断**：作者说清自己读到了什么，也说清判断只适用于何处。

不要用“这个细节体现了深刻主题”跳过前两层。先让读者看见，再解释；解释完成后就停，不把已经落地的句子再翻译一遍。

## 二、写作动作

### 1. 从文本中的不协调处起笔

引言和每节优先从一个具体的不协调处、词语、动作或叙事转折进入，例如“正坐在喜宴上，忽然哭了”，而不是从“《西游记》是一部关于成长的小说”这类泛论进入。

### 2. 一个段落完成一次观察

段落可遵循“看见 → 推想 → 限定”的节奏：

- 写清原文发生了什么，不虚构画面、心理或作者经历；
- 提出由此可支持的判断；
- 判断有争议或不足时，用范围、异说或材料来源限定它。

不需要每段都三步齐全，但不能只有抽象结论。

### 3. 让判断有署名，也有分寸

可以用“本文更愿意这样读”“就这一段的叙事顺序而言”“这未必意味着”等形式承担判断。禁止把个人阅读伪装成作者意图、学界定论或读者共同感受；也不要为制造真实感编造“我曾经”“朋友说过”等经历。

### 4. 信任读者

原文、动作或准确比喻已完成表达时，不追加“这说明”“这告诉我们”“换句话说”来重复同一层意思。必要的解释应增加新信息：位置、机制、反证、异说或范围。

### 5. 节奏服务于思考

长短句可以交错，句式可以变化；但不为了反模板而碎片化，不加入无关题外话。每节仍要有明确问题和证据推进，段末不强制收成可截图的结论句。

## 三、重点清理的机械模式

以下模式出现时先判断其是否承担必要逻辑；可以删改，但不做机械禁词替换：

| 模式 | 判断问题 | 优先修法 |
|---|---|---|
| 空泛重要性 | 这句话删去后是否少了可核查事实或新推论？ | 换成原文字句、情节动作或可定位研究。 |
| 模糊归因 | “有人/学界/专家”具体是谁？ | 写出作者、题名、页码或链接。 |
| 二元对立套话 | “不是……而是……”是否真正推进了区分？ | 保留有文本证据的对照；删掉只负责制造力度的排比。 |
| 三项整齐堆叠 | 三项是否各自必要，还是为了显得全面？ | 保留两项或改写成连续叙述。 |
| 抽象名词堆砌 | “自由、生命、秩序、意义”等是否落到文本？ | 补一个可见词、动作、顺序或删减。 |
| 解释复述 | 引文后是否只把原话换成白话再说一遍？ | 删除复述，或补充新的分析层。 |
| 万能金句 | 这句话能否原封不动挪到任一部名著？ | 让它回到本回人物、词句和论证边界。 |
| 通用积极结尾 | 是否只说“因此更有意义/启示”？ | 回答开头的问题，或在证据能到之处收束。 |

## 四、不应照搬的 Humanizer 规则

- 不把“第一人称”“混乱”“题外话”当作活人感指标。
- 不把所有“不是……而是……”或书面连接词当错；研究文章需要准确的转折与限定。
- 不追求口语化到削弱概念、版本和研究出处。
- 不为避开常见词而故意换词，术语应前后一致。
- 不以“检测分数”决定文章质量；证据链与解释边界优先。

## 五、交付前快速复核

1. 每一节是否至少有一个被细读的、可回查的原文现象？
2. 是否有引文后连续两句只在重复其情绪或意义？
3. 任何“重要、深刻、体现、揭示、说明、可以说”等抽象判断，是否有具体对象与证据？
4. 是否把本文判断、研究观点、原文事实清楚分开？
5. 收尾是否回到本文问题，而不是制造可脱离文本传播的漂亮句子？
