# 《西游记》表达学习候选库

> 用户终稿修改的跨篇学习资产。单次修改只形成候选；同一策略三篇综合后试运行，经用户确认才采用。

## 候选状态

`观察到` → `已归因` → `待跨篇验证` → `试运行` → `待用户确认` → `已采用` / `保留为例外` / `否决` / `退役`

## 记录字段

| 候选 ID | 来源文章/版本 | 修改位置与差异 | 表达功能 | 解决的读者问题 | application_scope | 主/辅助策略 | 是否改变研究责任 | 反例 | 当前状态 | 规则版本 | 用户确认 |
|---|---|---|---|---|---|---|---|---|---|---|

## 学习协议

1. 每篇用户确认终稿后立即复盘审核稿与终稿差异。
2. 先区分事实/引文、论题/边界、篇幅/平台、单篇例外和可迁移表达偏好；发布资产必须标记 `PUBLICATION_COPY`、`PLATFORM_TITLE` 或 `PLATFORM_ADAPTATION`，不得默认归入 `ARTICLE_BODY`。
3. 同一策略积累三篇后做横向综合；下一篇显式试运行。
4. 共同表达底色需跨至少两张策略卡的重复信号。
5. 规则版本化；用户未确认前不静默写回策略卡或全局规范。发布作用域的反馈不得自动改写正文策略；跨作用域迁移须有独立证据、正文试运行和用户确认。
